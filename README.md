My technical approach bridges mathematical economy balancing, exploit-proof network security, and modern UI/UX design to deliver experiences that retain players and maximize platform monetization.

- **End-to-End Systems Ownership:** From mathematical progression models to backend data persistence and frontend UI controllers.

## 🚀 Flagship Project: STARWEAVE

> **A Cosmic Gardening & Exponential RNG Mutation Simulator**  
> *Targeting 5,800+ DAU · 15+ ARPDAU · $10,000 USD/Month DevEx Run-Rate*

STARWEAVE combines high-retention agricultural progression with exponential RNG mutation rolling (inspired by *Sol's RNG* and *Grow a Garden*) and prestige transcendence mechanics.

### 📐 Engineering Highlights

| Subsystem | Architectural Implementation | Key Technical Features |
|---|---|---|
| **Data Persistence** | [`DataService.luau`](./src/server/Services/DataService.luau) | ProfileService wrapper with multi-server session locking, Studio mock fallback, and schema migrations |
| **Mutation Engine** | [`MutationService.luau`](./src/server/Services/MutationService.luau) | 7-tier exponential RNG mutation distribution with compound luck scaling (Normal to Primordial 500x) |
| **Garden Simulation** | [`GardenService.luau`](./src/server/Services/GardenService.luau) | 9-plot server-authoritative growth timers, harvesting validation, and 3:1 seed transmutation altar |
| **Monetization** | [`EconomyService.luau`](./src/server/Services/EconomyService.luau) | Idempotent `ProcessReceipt` transaction pipeline, 6 DevProducts, 6 Gamepasses, and Transcendence multiplier curves |
| **Interface System** | [`UILib.luau`](./src/client/UI/UILib.luau) | Centralized cosmic design tokens, 60 FPS spring animations, mobile-first safe zone compensation, and zero TextScaled blur |
